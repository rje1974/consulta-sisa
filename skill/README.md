# Skill consulta-sisa para Claude Code

## Instalación

Copiá `consulta-sisa.md` a tu carpeta de skills de Claude Code:

```bash
cp skill/consulta-sisa.md ~/.claude/skills/
```

## Uso

En cualquier conversación de Claude Code:

```
consultá SISA
```

Claude busca tu lista de CUITs, descarga el padrón y te muestra el reporte.
